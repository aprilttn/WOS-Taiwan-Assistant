
# WOS Taiwan Assistant

Traditional Chinese Discord bot for Whiteout Survival communities.

## About

WOS Taiwan Assistant is a community Discord bot designed for Whiteout Survival players and alliances.

The project is intended to support multiple Discord communities, not only personal use.

## Features

- Traditional Chinese interface
- Player and alliance management
- Gift code tools
- Notifications and reminders
- Web-based administration panel
- Player profile lookup by FID
- Player nickname tracking
- State transfer tracking
- Alliance and player data synchronization

## Player Data

This project plans to integrate external player data APIs to retrieve and synchronize:

- Player name
- Chief ID / FID
- State
- Furnace level
- Power
- Alliance information
- Nickname changes
- State transfer history

## Data Provider

Player data provided by WOS Control where applicable.

https://woscontrol.com/

This project is currently under active development.
